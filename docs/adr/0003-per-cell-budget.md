# 3. 核验策略按"每格预算"决策，而不是全局阈值

日期：2026-11-01
状态：已采纳

## 背景

拿到区域级分数之后，最自然的做法是设一个全局阈值：高于就放行，低于就转
人工。这个做法有两个问题：

1. **不同区域的风险差着量级。** 报销单上的一行备注和一个 8 万的合同金额，
   错一次的代价差几百倍。用同一个阈值，等于要么浪费人力，要么放过事故。
2. **转人工不是免费的。** 把 5% 的低分区域全丢给人，人是会被淹没的，而且
   看起来"这个系统在甩锅"。

反过来，"把所有低分区域都再跑一遍模型"也不行：一个页面几十个区域，
每个都重解析一遍，推理成本可能比人工复核还高。

## 决策

引入一个显式的成本模型和**逐格预算决策器**（`budget.py`）：

- 每个区域的动作空间固定：放行 / 重解析 / 择优 / 升级多模态 / 转人工；
- 每个动作有成本（rcu）和期望置信度增益；
- 决策目标是**在预算约束下最小化残余期望损失**，选效率（风险下降 ÷ 成本）
  最高的动作；
- 人工复核的成本被显式放进对照表：人工准确率 0.995、成本 8.0 rcu。效率上
  人工更划算时，就转人工——在低危格子上让人看是浪费，在高危格子上让人看
  可能比再跑三次模型更划算；
- 总预算按风险等级分配：致命字段 45%、高危 30%、中危 15%、低危 5%。

## 结果

- 决策有据可查：每个区域为什么这么处理、花了多少，都写进账本，可以事后审计。
- 成本可控：`total_budget` 是硬约束，超了自动降级到转人工。
- 天然适配不同业务：改 `CostModel` 和 `BudgetPolicy` 就能换成另一套经济账，
  不需要改代码结构。

## 备选方案

- **全局阈值**：简单，但把不同风险等级的字段一视同仁。
- **全部交给人工**：准确，但成本不可控，也浪费模型已经给出的信息。
- **全部交给模型**：成本不可控，而且模型解决不了"两个候选都错"的情况。
- **按区域数量平均分配预算**：比全局阈值好，但没考虑字段的实际风险等级。
